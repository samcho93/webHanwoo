Multi-Object Tracking (BoT-SORT)

A detector only tells us, frame by frame, “where the cattle are”. Deciding “is this the same animal as before?” and carrying the same ID forward is the job of multi-object tracking (MOT).

1. The three ingredients of tracking-by-detection

→
② Compute cost
IoU · appearance (ReID)

③ Assign

④ Track management

① Kalman filter — predicting the next position

Each track's state [x, y, w, h, vx, vy, vw, vh] is predicted into the next frame with a constant-velocity model and then corrected by the actual detection. Because a predicted position exists even during a brief occlusion, the track can be reconnected when the animal reappears.

② Cost — how likely is it the same animal?

  • IoU distance = 1 − (predicted box ∩ detected box) / (union). Very powerful for slow-moving cattle.
  • Appearance (ReID) distance: cosine distance between feature vectors of the image inside each box. Prevents swaps when cattle cross paths.

③ Hungarian algorithm — the 1:1 matching with minimal total cost

from scipy.optimize import linear_sum_assignment
import numpy as np
#            det A  det B  det C
C = np.array([[0.1,  0.9,  0.8],   # track 1
              [0.8,  0.2,  0.9],   # track 2
              [0.9,  0.7,  0.3]])  # track 3
rows, cols = linear_sum_assignment(C)   # → (0,0), (1,1), (2,2) total cost 0.6

Greedily pairing “the closest ones first” can lead to tangles, but the Hungarian algorithm guarantees the solution with the minimal total sum. We will use this algorithm again for offline stitching in the next lesson.

3. BoT-SORT settings for the barn

📄 configs/hanwoo_botsort.yaml
# BoT-SORT settings tuned for a Hanwoo barn (fixed camera, slow motion, occlusion by fences/pillars)
tracker_type: botsort
track_high_thresh: 0.35   # 1st association: high-confidence detections
track_low_thresh: 0.10    # 2nd association: keep existing tracks alive with occluded (low-confidence) detections
new_track_thresh: 0.45    # start new IDs conservatively -> avoids ID explosion
track_buffer: 120         # remember lost tracks for 5 s (24 fps) -> survives occlusion behind pillars
match_thresh: 0.85
fuse_score: True
gmc_method: none          # fixed camera: no camera-motion compensation needed (faster, no false correction)
proximity_thresh: 0.5
appearance_thresh: 0.75
with_reid: True           # use the detector's internal features as ReID embeddings (model: auto)
model: auto

with_reid: True, model: auto reuses the internal features of the YOLO detector as appearance embeddings, without a separate ReID model. Our fine-tuned detector has already learned what Hanwoo look like, so these become usable appearance features at no extra cost.

4. Detection + tracking + feature collection code

Calling Ultralytics' model.track(frame, persist=True) on every frame keeps the tracker state internally. At the same time, we collect the appearance histograms and motion energy (frame difference) used in later stages.

📄 hanwoo/detect_track.py
"""Stage 1: detection (YOLO) + online tracking (BoT-SORT) + per-frame feature collection.

Returns a single pandas DataFrame (frame × object):
  frame, tid, x1,y1,x2,y2, conf, motion  + appearance histograms (separate dict)
"""
from __future__ import annotations

from pathlib import Path

import cv2
import numpy as np
import pandas as pd

from .config import PipelineConfig

# Classes treated as 'cow' with a COCO-pretrained model (horse covers cows misclassified as horses; sheep is excluded because it fires on hay bales)
COCO_ANIMAL_CLASSES = [17, 19]


def load_model(cfg: PipelineConfig):
    from ultralytics import YOLO

    w = cfg.weights if Path(cfg.weights).exists() else cfg.fallback_weights
    model = YOLO(w)
    # single-class (hanwoo) model: use all classes; COCO (80 classes) model: cows/horses only
    classes = None if len(model.names) == 1 else COCO_ANIMAL_CLASSES
    print(f"[detector] {w}  ({'fine-tuned hanwoo' if classes is None else 'COCO pretrained'})")
    return model, classes


def appearance_hist(frame_hsv: np.ndarray, box) -> np.ndarray:
    """H-S 2D histogram of the bbox centre region (minimises fence/background influence) - appearance feature."""
    x1, y1, x2, y2 = [int(v) for v in box]
    w, h = x2 - x1, y2 - y1
    cx1, cy1 = x1 + w // 5, y1 + h // 5
    cx2, cy2 = x2 - w // 5, y2 - h // 5
    roi = frame_hsv[max(cy1, 0):max(cy2, 1), max(cx1, 0):max(cx2, 1)]
    if roi.size == 0:
        return np.zeros(16 * 8, np.float32)
    hist = cv2.calcHist([roi], [0, 1], None, [16, 8], [0, 180, 0, 256]).flatten()
    s = hist.sum()
    return (hist / s).astype(np.float32) if s > 0 else hist.astype(np.float32)


def run_detect_track(video_path: str | Path, cfg: PipelineConfig, verbose_every: int = 500):
    model, classes = load_model(cfg)
    cap = cv2.VideoCapture(str(video_path))
    fps = cap.get(cv2.CAP_PROP_FPS) or 24.0
    n_total = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    W = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
    H = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))

    rows, feats = [], {}
    prev_gray = None
    fi = 0
    while True:
        ok, frame = cap.read()
        if not ok or (cfg.max_frames and fi >= cfg.max_frames):
            break
        gray = cv2.GaussianBlur(cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY), (5, 5), 0)
        hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
        res = model.track(
            frame, persist=True, tracker=cfg.tracker_cfg, imgsz=cfg.imgsz,
            conf=cfg.conf, iou=cfg.iou, classes=classes, agnostic_nms=True,
            device=cfg.device, verbose=False,
        )[0]
        if res.boxes is not None and res.boxes.id is not None:
            xyxy = res.boxes.xyxy.cpu().numpy()
            ids = res.boxes.id.cpu().numpy().astype(int)
            confs = res.boxes.conf.cpu().numpy()
            diff = cv2.absdiff(gray, prev_gray) if prev_gray is not None else None
            for b, t, c in zip(xyxy, ids, confs):
                x1, y1, x2, y2 = np.clip(b, 0, [W, H, W, H]).astype(int)
                motion = 0.0
                if diff is not None and x2 > x1 and y2 > y1:
                    motion = float(diff[y1:y2, x1:x2].mean())
                rows.append((fi, int(t), *map(float, b), float(c), motion))
                feats[(fi, int(t))] = appearance_hist(hsv, b)
        prev_gray = gray
        fi += 1
        if verbose_every and fi % verbose_every == 0:
            print(f"  [track] {fi}/{n_total} frames")
    cap.release()

    df = pd.DataFrame(rows, columns=["frame", "tid", "x1", "y1", "x2", "y2", "conf", "motion"])
    meta = dict(fps=fps, width=W, height=H, n_frames=fi, video=str(video_path))
    return df, feats, meta
