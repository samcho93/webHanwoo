다중 객체 추적 (BoT-SORT)

검출기는 프레임마다 “소가 어디에 있는지” 만 알려 줍니다. “이 소가 아까 그 소인지” 를 판단해 같은 ID 를 이어 주는 것이 다중 객체 추적(MOT, Multi-Object Tracking) 입니다.

1. Tracking-by-Detection 의 3요소

① 예측
Kalman 필터
→
② 비용 계산
IoU · 외형(ReID)
→
③ 할당
Hungarian 알고리즘
→
④ 트랙 관리
생성 · 유지 · 삭제

① Kalman 필터 — 다음 위치 예측

각 트랙의 상태 [x, y, w, h, vx, vy, vw, vh] 를 등속 모델로 다음 프레임에 예측하고, 실제 검출로 보정합니다. 잠깐 가려져도 예측 위치가 있으므로 다시 나타났을 때 연결할 수 있습니다.

② 비용 — 얼마나 같은 소 같은가

  • IoU 거리 = 1 − (예측 박스 ∩ 검출 박스) / (합집합). 느리게 움직이는 소에게 매우 강력.
  • 외형(ReID) 거리: 박스 안 이미지의 특징 벡터 코사인 거리. 소들이 교차할 때 뒤바뀜을 막음.

③ Hungarian 알고리즘 — 전체 비용이 최소가 되는 1:1 짝짓기

from scipy.optimize import linear_sum_assignment
import numpy as np
#            검출A  검출B  검출C
C = np.array([[0.1,  0.9,  0.8],   # 트랙1
              [0.8,  0.2,  0.9],   # 트랙2
              [0.9,  0.7,  0.3]])  # 트랙3
rows, cols = linear_sum_assignment(C)   # → (0,0), (1,1), (2,2) 총비용 0.6

“가장 가까운 것끼리” 탐욕적으로 짝지으면 꼬일 수 있지만, Hungarian 은 전체 합이 최소인 해를 보장합니다. 이 알고리즘은 다음 레슨의 오프라인 정합에서도 다시 씁니다.

2. ByteTrack 과 BoT-SORT

ByteTrackBoT-SORT
핵심 아이디어낮은 신뢰도 검출도 버리지 않고 2단계 매칭에 사용 → 가려진 소 유지ByteTrack + ReID 외형 + 카메라 움직임 보정(GMC)
장점빠르고 단순교차·가림 후 ID 유지가 더 강함
이 축사에서소가 교차하면 ID 가 바뀌기 쉬움고정 카메라이므로 GMC 는 끄고 ReID 를 켬

3. 축사용 BoT-SORT 설정

📄 configs/hanwoo_botsort.yaml
# 한우 축사(고정 카메라, 느린 이동, 펜스·기둥 가림) 에 맞춘 BoT-SORT 설정
tracker_type: botsort
track_high_thresh: 0.35   # 1차 매칭: 신뢰도 높은 검출
track_low_thresh: 0.10    # 2차 매칭: 가려진(낮은 신뢰도) 검출로도 기존 트랙 유지
new_track_thresh: 0.45    # 새 ID 생성은 보수적으로 → ID 남발 방지
track_buffer: 120         # 5초(24fps) 동안 사라진 트랙 기억 → 기둥 뒤 가림 대응
match_thresh: 0.85
fuse_score: True
gmc_method: none          # 고정 카메라: 카메라 움직임 보정 불필요 (속도↑, 오보정 방지)
proximity_thresh: 0.5
appearance_thresh: 0.75
with_reid: True           # 검출기 내부 특징을 ReID 임베딩으로 사용 (model: auto)
model: auto

with_reid: True, model: auto 는 별도 ReID 모델 없이 YOLO 검출기 내부 특징을 외형 임베딩으로 재사용합니다. 우리가 미세조정한 검출기는 한우 외형을 이미 학습했으므로 추가 비용 없이 쓸 만한 외형 특징이 됩니다.

4. 검출 + 추적 + 특징 수집 코드

Ultralytics 의 model.track(frame, persist=True) 를 프레임마다 호출하면 내부에 추적기 상태가 유지됩니다. 동시에, 이후 단계에서 쓸 외형 히스토그램과 motion energy(프레임 차) 를 수집합니다.

📄 hanwoo/detect_track.py
"""1단계: 검출(YOLO) + 온라인 추적(BoT-SORT) + 프레임별 특징 수집.

결과는 pandas DataFrame 한 장(프레임 × 객체)으로 반환한다.
  frame, tid, x1,y1,x2,y2, conf, motion  + 외형 히스토그램(별도 dict)
"""
from __future__ import annotations

from pathlib import Path

import cv2
import numpy as np
import pandas as pd

from .config import PipelineConfig

# COCO 사전학습 모델 사용 시 '소'로 간주할 클래스 (소가 말로 오분류되는 경우 보완, sheep 은 곤포 오검출로 제외)
COCO_ANIMAL_CLASSES = [17, 19]


def load_model(cfg: PipelineConfig):
    from ultralytics import YOLO

    w = cfg.weights if Path(cfg.weights).exists() else cfg.fallback_weights
    model = YOLO(w)
    # 클래스 1개(hanwoo) 학습 모델이면 전체 사용, COCO(80 클래스) 모델이면 소/말만 사용
    classes = None if len(model.names) == 1 else COCO_ANIMAL_CLASSES
    print(f"[detector] {w}  ({'fine-tuned hanwoo' if classes is None else 'COCO pretrained'})")
    return model, classes


def appearance_hist(frame_hsv: np.ndarray, box) -> np.ndarray:
    """bbox 중앙부(펜스·배경 영향 최소화)의 H-S 2D 히스토그램 (외형 특징)."""
    x1, y1, x2, y2 = [int(v) for v in box]
    w, h = x2 - x1, y2 - y1
    cx1, cy1 = x1 + w // 5, y1 + h // 5
    cx2, cy2 = x2 - w // 5, y2 - h // 5
    roi = frame_hsv[max(cy1, 0):max(cy2, 1), max(cx1, 0):max(cx2, 1)]
    if roi.size == 0:
        return np.zeros(16 * 8, np.float32)
    hist = cv2.calcHist([roi], [0, 1], None, [16, 8], [0, 180, 0, 256]).flatten()
    s = hist.sum()
    return (hist / s).astype(np.float32) if s > 0 else hist.astype(np.float32)


def run_detect_track(video_path: str | Path, cfg: PipelineConfig, verbose_every: int = 500):
    model, classes = load_model(cfg)
    cap = cv2.VideoCapture(str(video_path))
    fps = cap.get(cv2.CAP_PROP_FPS) or 24.0
    n_total = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    W = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
    H = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))

    rows, feats = [], {}
    prev_gray = None
    fi = 0
    while True:
        ok, frame = cap.read()
        if not ok or (cfg.max_frames and fi >= cfg.max_frames):
            break
        gray = cv2.GaussianBlur(cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY), (5, 5), 0)
        hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
        res = model.track(
            frame, persist=True, tracker=cfg.tracker_cfg, imgsz=cfg.imgsz,
            conf=cfg.conf, iou=cfg.iou, classes=classes, agnostic_nms=True,
            device=cfg.device, verbose=False,
        )[0]
        if res.boxes is not None and res.boxes.id is not None:
            xyxy = res.boxes.xyxy.cpu().numpy()
            ids = res.boxes.id.cpu().numpy().astype(int)
            confs = res.boxes.conf.cpu().numpy()
            diff = cv2.absdiff(gray, prev_gray) if prev_gray is not None else None
            for b, t, c in zip(xyxy, ids, confs):
                x1, y1, x2, y2 = np.clip(b, 0, [W, H, W, H]).astype(int)
                motion = 0.0
                if diff is not None and x2 > x1 and y2 > y1:
                    motion = float(diff[y1:y2, x1:x2].mean())
                rows.append((fi, int(t), *map(float, b), float(c), motion))
                feats[(fi, int(t))] = appearance_hist(hsv, b)
        prev_gray = gray
        fi += 1
        if verbose_every and fi % verbose_every == 0:
            print(f"  [track] {fi}/{n_total} frames")
    cap.release()

    df = pd.DataFrame(rows, columns=["frame", "tid", "x1", "y1", "x2", "y2", "conf", "motion"])
    meta = dict(fps=fps, width=W, height=H, n_frames=fi, video=str(video_path))
    return df, feats, meta
