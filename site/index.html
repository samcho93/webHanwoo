Course Introduction and Overview

In this course we build, from start to finish, a Python program that takes video of a Hanwoo (Korean native cattle) barn shot with a fixed camera, assigns an ID to every individual animal, and automatically measures each animal's distance travelled, speed, behavior state and activity index. We don't stop at using a pretrained YOLO as-is: we train it ourselves to fit the barn environment, and we fix broken tracking IDs with an offline stitching algorithm.

│  ├─ render.py             # ⑤ output video rendering
│  ├─ dashboard.py          # ⑤ HTML dashboard
│  └─ pipeline.py           # wires everything together
├─ configs/hanwoo_botsort.yaml  # tracker settings for the barn
├─ scripts/
│  ├─ prepare_dataset.py    # build training data by auto-labeling
│  ├─ train.py              # YOLO fine-tuning
│  ├─ prepare_reid.py       # self-supervised ReID data
│  ├─ train_reid.py         # ReID training and evaluation
│  ├─ identity_sheet.py     # ID contact sheet
│  ├─ compare_trackers.py   # tracking algorithm comparison experiment
│  └─ build_site.py         # generates this course site

Run it in one line

python run_activity.py E:/Video/cow

For every mp4 in the folder, outputs/<video_name>/ receives an output video (*_tracked.mp4), per-frame data (tracks_activity.csv), a per-animal summary (summary.csv) and a dashboard (dashboard.html), and an overall summary is generated in outputs/index.html.

What you need

  • A Windows/Linux PC with an NVIDIA GPU (this course: TITAN RTX 24GB, Windows 11). It works without a GPU, but slowly.
  • Basic Python (functions, lists), and at least having heard of pandas/NumPy
  • Barn video (this course: 854×480, 24fps, 10 clips · about 30 minutes in total)
