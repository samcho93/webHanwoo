Applying to New Videos and Extending

How to apply the system to videos from other barns and other cameras, and directions for extending it to achieve higher accuracy.

1. Applying it directly to other videos

# single video
python run_activity.py D:/farm2/cam1_0601.mp4
# whole folder, with a custom output location
python run_activity.py D:/farm2 --out D:/farm2_results
# if the animals are a different size, change the reference height for perspective (e.g. mostly calves: 1.0 m)
python run_activity.py D:/farm2 --cow-height 1.0
# dashboard and CSV only, fast (skip video rendering)
python run_activity.py D:/farm2 --no-video

The perspective model (h(y)) is fitted automatically for each video, so no extra setup is needed even if the camera position changes.

4. Extension directions

(1) Accurate distance with a homography

import cv2, numpy as np
img_pts   = np.float32([[150,190],[700,180],[840,300],[20,310]])   # four floor corners on screen
world_pts = np.float32([[0,0],[20,0],[20,12],[0,12]])              # real-world coordinates (m)
Hm = cv2.getPerspectiveTransform(img_pts, world_pts)
# animal's foot position (bottom center of bbox) to floor coordinates (m)
foot = np.float32([[[cx, y2]]]); world = cv2.perspectiveTransform(foot, Hm)

Assuming the floor is a plane, this converts pixels to real meters accurately. If the feet are often hidden by the fence, use the foot position estimated from the perspective model instead of the bottom of the bbox.

(2) Identifying animals across multiple days

The ReID in Lesson 08 distinguishes N animals within a single video. To call the same animal by the same number across videos from different days, store each animal's representative embedding in an “animal registry” and match the N slots of a new video to the registry with the Hungarian algorithm. Combining this with OCR of ear-tag numbers can link animals to their real traceability numbers, and having a person verify a few segments and adding them to the ReID training data improves accuracy further.

(3) Posture and behavior recognition

If you label lying / standing / feeding as separate classes and train YOLO as a multi-class model, you can directly measure physiological indicators such as rumination and resting time.

(4) Real-time operation (RTSP camera)

The system can be extended to read an IP camera stream with cv2.VideoCapture("rtsp://..."), run online tracking, perform offline stitching and aggregation at a fixed interval (e.g. every 10 minutes), store the results in a database (e.g. SQLite, InfluxDB), and refresh the dashboard periodically.

(5) Abnormal-animal alerts

Build a baseline of each animal's daily activity index (mean ± standard deviation over the last 7 days) and raise an alert on large deviations: sharp rise in activity → possible estrus; sharp drop → possible illness or lameness.

Wrapping up

What this course built is a complete pipeline running detection → tracking → stitching → measurement → visualization. Each stage is an independent module, so when a better detector, tracker or metric comes along, you only need to swap that module.
