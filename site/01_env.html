Setting Up the Environment

We set up an environment for running deep learning on a GPU from scratch. Every result in this course was produced in an environment built with exactly the commands below.

OSWindows 11Linux/macOS differ only slightly in commands
GPU / driverNVIDIA TITAN RTX 24GB / driver 610.xAccelerates training and inference
Python3.14Programming language
PyTorch2.11.0 + CUDA 12.8 build (cu128)Deep learning framework
Ultralytics8.4.xYOLO11 detection, training and tracking (BoT-SORT/ByteTrack)

1. Check the GPU driver

PyTorch does not require a separate CUDA Toolkit install (the CUDA runtime ships inside the wheel). You only need an up-to-date driver.

nvidia-smi

If the CUDA Version at the top right of the output is at least the CUDA version of the PyTorch build you will install (e.g. 12.8), you're fine. If it is lower, update your NVIDIA driver.

2. Install Python

Install 3.12 or later from python.org. On the installer screen, check “Add python.exe to PATH”. If you have several versions, you can list and pick one with the Windows py launcher.

py -0p          # list installed Pythons
python --version
Anaconda works too, but this course uses a standard venv, which is lightweight and easy to reproduce.

3. Project folder and virtual environment

A virtual environment (venv) gives each project its own isolated package space, preventing version conflicts.

mkdir D:\Work\Web\webHanwoo
cd D:\Work\Web\webHanwoo
py -3.14 -m venv .venv

Activate it (depending on your terminal):

# PowerShell
.\.venv\Scripts\Activate.ps1
# cmd
.venv\Scripts\activate.bat
# Git Bash / Linux / macOS
source .venv/Scripts/activate      # on Linux/macOS use .venv/bin/activate
If PowerShell reports that “running scripts is disabled on this system”, run this once: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

4. Install PyTorch (GPU build)

A plain pip install torch may install the CPU build on Windows. Always specify the CUDA index URL. (Check pytorch.org for the command that matches your setup.)

python -m pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128

Verify the install:

python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
# 2.11.0+cu128 True NVIDIA TITAN RTX

5. YOLO (Ultralytics) and the remaining packages

pip install ultralytics pandas scipy lap
python -c "import ultralytics; ultralytics.checks()"

ultralytics also installs OpenCV, NumPy, matplotlib and more. lap is a fast linear assignment (Hungarian) library used by the tracker. Record the versions for reproducibility:

pip freeze > requirements.lock.txt

On a new PC you can install everything at once with requirements.txt:

📄 requirements.txt

6. Install FFmpeg

OpenCV's default mp4 codec (mp4v) does not play in web browsers. To view output videos directly in the dashboard, we encode them to H.264 with FFmpeg.

  1. Download ffmpeg-release-essentials.zip from gyan.dev → extract it to D:\ffmpeg
  2. Add D:\ffmpeg\bin to the system Path environment variable → restart the terminal
  3. Check: ffmpeg -version

(Linux: sudo apt install ffmpeg, macOS: brew install ffmpeg)

7. Prepare pretrained weights

YOLO weights are downloaded automatically on first use. In this course we keep them together in models/.

mkdir models
cd models
python -c "from ultralytics import YOLO; YOLO('yolo11s.pt'); YOLO('yolo11x.pt')"
cd ..
ModelSizePurpose
yolo11s.ptabout 19MBstudent: used for actual tracking after fine-tuning (fast)
yolo11x.ptabout 110MBteacher: used to auto-label training data (accurate, slow)

8. Smoke test (Hello YOLO)

python -c "from ultralytics import YOLO; r=YOLO('models/yolo11s.pt').predict('https://ultralytics.com/images/bus.jpg', device=0); print(r[0].boxes.cls)"

If a list of class indices is printed, your environment is ready.

9. Editor

We recommend VS Code with the Python extension. Under Ctrl+Shift+P → Python: Select Interpreter, choose the Python inside .venv.

Common problems

SymptomCause / fix
torch.cuda.is_available() is FalseCPU build of torch installed → pip uninstall torch torchvision, then reinstall with the step 4 command (--index-url). Also check the driver version.
CUDA out of memory during trainingLower it with --batch 8 or --imgsz 640
DataLoader error / endless hang when training starts on WindowsThe script needs an if __name__ == "__main__": guard (included in this course's scripts), or use workers=0
ffmpeg not foundRestart the terminal (and VS Code) after adding it to Path
Output mp4 won't play in the browsermp4v codec → encode with FFmpeg libx264 + -pix_fmt yuv420p
OpenCV imread fails on paths containing Korean charactersKeep videos and data on ASCII-only paths, or use cv2.imdecode(np.fromfile(path))
