개발 환경 구축

GPU 로 딥러닝을 돌리기 위한 환경을 처음부터 구성합니다. 이 강좌의 모든 결과는 아래 명령 그대로 구축한 환경에서 만들어졌습니다.

구성요소본 강좌 버전역할
OSWindows 11Linux/macOS 도 명령만 조금 다름
GPU / 드라이버NVIDIA TITAN RTX 24GB / 드라이버 610.x학습·추론 가속
Python3.14프로그래밍 언어
PyTorch2.11.0 + CUDA 12.8 빌드 (cu128)딥러닝 프레임워크
Ultralytics8.4.xYOLO11 검출·학습·추적(BoT-SORT/ByteTrack)
OpenCV, pandas, SciPy, lap최신영상 처리, 데이터 처리, Hungarian 알고리즘
FFmpeg정적 빌드영상 정보 확인, 브라우저 호환 H.264 인코딩

1. GPU 드라이버 확인

PyTorch 는 CUDA Toolkit 을 따로 설치하지 않아도 됩니다(휠 안에 CUDA 런타임 포함). 드라이버만 최신이면 됩니다.

nvidia-smi

출력 오른쪽 위 CUDA Version 이 설치할 PyTorch 의 CUDA 버전(예: 12.8) 이상이면 OK. 낮으면 NVIDIA 드라이버를 업데이트하세요.

2. Python 설치

python.org 에서 3.12 이상을 설치합니다. 설치 화면에서 “Add python.exe to PATH” 를 체크하세요. 여러 버전이 있으면 Windows 의 py 런처로 확인/선택할 수 있습니다.

py -0p          # 설치된 파이썬 목록
python --version
Anaconda 를 써도 되지만, 이 강좌는 가볍고 재현이 쉬운 표준 venv 를 사용합니다.

3. 프로젝트 폴더와 가상환경

가상환경(venv)은 프로젝트마다 독립된 패키지 공간을 만들어 버전 충돌을 막습니다.

mkdir D:\Work\Web\webHanwoo
cd D:\Work\Web\webHanwoo
py -3.14 -m venv .venv

활성화 (터미널 종류별):

# PowerShell
.\.venv\Scripts\Activate.ps1
# cmd
.venv\Scripts\activate.bat
# Git Bash / Linux / macOS
source .venv/Scripts/activate      # Linux/macOS 는 .venv/bin/activate
PowerShell 에서 “스크립트를 실행할 수 없습니다” 오류가 나면 한 번만 실행: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

4. PyTorch (GPU 버전) 설치

그냥 pip install torch 하면 Windows 에서는 CPU 버전이 설치될 수 있습니다. 반드시 CUDA 인덱스 URL 을 지정합니다. (pytorch.org 에서 자신의 환경에 맞는 명령을 확인)

python -m pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128

설치 확인:

python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
# 2.11.0+cu128 True NVIDIA TITAN RTX

5. YOLO(Ultralytics) 와 나머지 패키지

pip install ultralytics pandas scipy lap
python -c "import ultralytics; ultralytics.checks()"

ultralytics 가 OpenCV, NumPy, matplotlib 등을 함께 설치합니다. lap 은 추적기에서 쓰는 빠른 선형 할당(Hungarian) 라이브러리입니다. 재현을 위해 버전을 기록해 둡니다:

pip freeze > requirements.lock.txt

새 PC 에서는 requirements.txt 로 한 번에 설치할 수 있습니다:

📄 requirements.txt
# GPU 버전 torch 는 먼저 별도로 설치:

opencv-python>=4.10
numpy
pandas
scipy

PySide6>=6.7          # 실시간 추적 프로그램 GUI (live_app.py)

6. FFmpeg 설치

OpenCV 의 기본 mp4 코덱(mp4v)은 웹 브라우저에서 재생되지 않습니다. 결과 영상을 대시보드에서 바로 보려면 FFmpeg 로 H.264 인코딩합니다.

  1. gyan.dev 에서 ffmpeg-release-essentials.zip 다운로드 → D:\ffmpeg 에 압축 해제
  2. 시스템 환경변수 Path 에 D:\ffmpeg\bin 추가 → 터미널 재시작
  3. 확인: ffmpeg -version

(Linux: sudo apt install ffmpeg, macOS: brew install ffmpeg)

7. 사전학습 가중치 준비

YOLO 가중치는 처음 사용할 때 자동 다운로드됩니다. 이 강좌는 models/ 에 모아 둡니다.

mkdir models
cd models
python -c "from ultralytics import YOLO; YOLO('yolo11s.pt'); YOLO('yolo11x.pt')"
cd ..
모델크기용도
yolo11s.pt약 19MBstudent: 미세조정 후 실제 추적에 사용 (빠름)
yolo11x.pt약 110MBteacher: 학습 데이터 자동 라벨링에 사용 (정확, 느림)

8. 동작 확인 (Hello YOLO)

python -c "from ultralytics import YOLO; r=YOLO('models/yolo11s.pt').predict('https://ultralytics.com/images/bus.jpg', device=0); print(r[0].boxes.cls)"

클래스 번호 목록이 출력되면 환경 구축 완료입니다.

9. 편집기

VS Code + Python 확장을 권장합니다. Ctrl+Shift+P → Python: Select Interpreter 에서 .venv 의 파이썬을 선택하세요.

자주 만나는 문제

증상원인 / 해결
torch.cuda.is_available() 가 FalseCPU 버전 torch 설치됨 → pip uninstall torch torchvision 후 4단계 명령(--index-url) 으로 재설치. 드라이버 버전도 확인.
학습 중 CUDA out of memory--batch 8 또는 --imgsz 640 으로 낮추기
Windows 에서 학습 시작 시 DataLoader 오류/무한 대기스크립트에 if __name__ == "__main__": 가드 필수 (본 강좌 스크립트에 포함), 또는 workers=0
ffmpeg 를 찾을 수 없음Path 등록 후 터미널(및 VS Code) 재시작
결과 mp4 가 브라우저에서 재생 안 됨mp4v 코덱 → FFmpeg libx264 + -pix_fmt yuv420p 로 인코딩
한글 경로에서 OpenCV imread 실패영상·데이터는 영문 경로에 두거나 cv2.imdecode(np.fromfile(path)) 사용
