4. 결과 해석과 한계

  • 최종 ID 수 vs 실제 두수: 정합 후 ID 수가 축사 두수(약 11~13)에 가까울수록 좋습니다. 남는 초과 ID 는 주로 ① 화면 가장자리에서 잠깐 보이는 옆 칸의 소, ② 오래 가려져 있다가 멀리서 다시 나타난 소입니다.
  • 긴 영상(cow03, 22분)은 2단계 정합만으로는 ID 가 29개 남았지만, ReID + 고정 개체군 배정(레슨 08) 후 추정 두수 N 과 같은 수로 유지됩니다.
  • 절대 거리는 체고 기반 근사이므로 ±20~30% 오차가 있을 수 있습니다. 그러나 같은 카메라 안에서의 개체 간·시간대 간 상대 비교는 신뢰할 수 있습니다.
  • 정답(Ground Truth) ID 라벨이 있으면 MOTA, IDF1, HOTA 등 표준 추적 지표로 정량 평가할 수 있습니다 (TrackEval 라이브러리).
