YOLO11x(teacher)로 축사 영상의 프레임을 자동 라벨링해 YOLO 형식 데이터셋을 만듭니다. 사람의 라벨링 없이 약 1,100장, 11,000개 이상의 박스를 확보합니다.

1. YOLO 데이터셋 형식

data/hanwoo_ds/
├─ hanwoo.yaml          # 경로·클래스 정의
├─ images/train/cow01_000024.jpg ...
├─ images/val/...
├─ labels/train/cow01_000024.txt ...   # 이미지와 같은 이름
└─ labels/val/...

라벨 파일 한 줄 = 박스 하나: 클래스 x중심 y중심 너비 높이 (모두 0~1 로 정규화)

0 0.632164 0.237500 0.068493 0.135417
0 0.401639 0.264583 0.049180 0.120833

2. 좋은 자동 라벨을 위한 4가지 장치

장치이유
영상 단위 train/val 분리 (val = cow02, cow09)같은 영상의 이웃 프레임은 거의 똑같다. 섞으면 검증 점수가 부풀려져 ‘다른 영상에서의 성능’ 을 알 수 없다.
프레임 간격 샘플링 (1초, 긴 영상은 3초)중복 프레임 제거, 22분 영상이 데이터를 독점하지 않도록
TTA(augment=True) + 고해상도 1280teacher 성능을 최대로: 좌우반전·다중 스케일 추론 결과를 합침
무시 영역(ignore region): 신뢰도 0.15~0.40 박스는 회색으로 칠함애매한 박스를 정답으로 넣으면 오라벨, 빼면 ‘배경’ 으로 학습되어 소를 배경이라고 가르치게 된다. 회색으로 지워 둘 다 피한다.
