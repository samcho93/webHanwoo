숫자만으로는 현장에서 쓰기 어렵습니다. 두 가지 결과물을 만듭니다: ① 개체 ID·궤적·실시간 패널이 그려진 결과 영상, ② 개체별 지표를 한눈에 보는 HTML 대시보드.

1. 결과 영상

  • ID 별 고유 색: 황금비(0.618…)로 색상환을 돌려 이웃 ID 끼리 색이 잘 구분되게
  • 보간 구간(0.5초 이하의 순간 누락)만 얇은 박스로 표시, 궤적은 실제 검출 위치로만 그림 → 소가 없는 곳에 경로가 생기지 않음
  • 박스 오른쪽 위 점: 회색=휴식, 주황=국소활동, 초록=보행
  • FFmpeg 파이프로 프레임을 직접 넘겨 H.264 / yuv420p / faststart 인코딩 → 브라우저에서 바로 재생, 스트리밍 시작이 빠름

2. 대시보드

영상마다 outputs/<영상>/dashboard.html, 전체 요약 outputs/index.html 이 생성됩니다. 서버 없이 더블클릭으로 열리는 단일 HTML 이고, 그래프는 Plotly.js 를 씁니다.
