A detector only tells us, frame by frame, “where the cattle are”. Deciding “is this the same animal as before?” and carrying the same ID forward is the job of multi-object tracking (MOT).

① Kalman filter — predicting the next position

Each track's state [x, y, w, h, vx, vy, vw, vh] is predicted into the next frame with a constant-velocity model and then corrected by the actual detection. Because a predicted position exists even during a brief occlusion, the track can be reconnected when the animal reappears.

② Cost — how likely is it the same animal?

  • IoU distance = 1 − (predicted box ∩ detected box) / (union). Very powerful for slow-moving cattle.
  • Appearance (ReID) distance: cosine distance between feature vectors of the image inside each box. Prevents swaps when cattle cross paths.

③ Hungarian algorithm — the 1:1 matching with minimal total cost

from scipy.optimize import linear_sum_assignment
import numpy as np
#            det A  det B  det C
C = np.array([[0.1,  0.9,  0.8],   # track 1
              [0.8,  0.2,  0.9],   # track 2
              [0.9,  0.7,  0.3]])  # track 3
rows, cols = linear_sum_assignment(C)   # → (0,0), (1,1), (2,2) total cost 0.6

Greedily pairing “the closest ones first” can lead to tangles, but the Hungarian algorithm guarantees the solution with the minimal total sum. We will use this algorithm again for offline stitching in the next lesson.

Calling Ultralytics' model.track(frame, persist=True) on every frame keeps the tracker state internally. At the same time, we collect the appearance histograms and motion energy (frame difference) used in later stages.

5. Which tracker is best? — a comparison experiment

We have no ground-truth ID labels, so we compare with proxy metrics (scripts/compare_trackers.py). The closer the ID/herd-size ratio is to 1.0, and the closer the number of full-length IDs (IDs kept for at least 90% of the video) is to the herd size, the better.
