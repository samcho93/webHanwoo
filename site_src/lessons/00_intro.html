고정 카메라로 촬영한 한우 축사 영상에서 소 한 마리 한 마리에 ID를 부여하고, 각 개체의 이동거리·속도·행동 상태·활동지수를 자동으로 측정하는 파이썬 프로그램을 처음부터 끝까지 만들어 봅니다. 사전학습 YOLO를 그대로 쓰는 데서 멈추지 않고, 축사 환경에 맞게 직접 학습시키고, 추적 ID가 끊기는 문제를 오프라인 정합 알고리즘으로 해결합니다.

검출YOLO11s 를 축사 영상으로 미세조정 (teacher-student 자동 라벨링)원거리·가려진 소의 낮은 신뢰도, 사료 곤포(베일)를 동물로 오검출

ID 정합원근 정규화 거리 + 외형 히스토그램 비용 → Hungarian 최적 연결기둥·펜스 뒤로 사라졌다 나타날 때 ID가 바뀌는 문제
활동량체고 기준 원근 보정, 중앙차분 속도, 프레임차 motion energy화면 위·아래에서 같은 이동이 다른 픽셀 거리로 보이는 문제, bbox 떨림
시각화OpenCV + FFmpeg(H.264), Plotly 대시보드사람이 바로 이해할 수 있는 결과물

│  ├─ prepare_dataset.py    # 자동 라벨링으로 학습 데이터 구축

한 줄 실행

python run_activity.py E:/Video/cow

폴더 안의 모든 mp4 마다 outputs/<영상명>/ 에 결과 영상(*_tracked.mp4), 프레임별 데이터(tracks_activity.csv), 개체 요약(summary.csv), 대시보드(dashboard.html)가 만들어지고, outputs/index.html 에 전체 요약이 생성됩니다.

수강 준비물

  • NVIDIA GPU 가 있는 Windows/Linux PC (본 강좌: TITAN RTX 24GB, Windows 11). GPU 없이도 동작하지만 느립니다.
  • 파이썬 기초(함수, 리스트), pandas/NumPy 를 들어본 정도
  • 축사 영상 (본 강좌: 854×480, 24fps, 10개 · 총 약 30분)
각 레슨의 코드 블록은 저장소의 실제 소스 파일에서 자동으로 삽입됩니다. 강좌와 코드가 항상 일치합니다.
